assistant: To effectively manage agents within the Multi-Tenant AI Chat Agent System, you'll need to store the following data:

1. **Agents Table**:
   - **id**: Unique identifier for the agent (UUID).
   - **name**: The name of the agent.
   - **context**: The system prompt or context associated with the agent.
   - **created_at**: The timestamp indicating when the agent was created.

2. **Files Table**:
   - **id**: Unique identifier for each file (UUID).
   - **agent_id**: Foreign key linking to the agent's ID.
   - **file_name**: The original name of the uploaded file.
   - **file_url**: The storage location of the file.
   - **created_at**: The timestamp of when the file was uploaded.

3. **Chats Table**:
   - **id**: Unique identifier for each chat session (UUID).
   - **agent_id**: Foreign key linking to the agent's ID.
   - **client_id**: Foreign key linking to the client's ID (optional).
   - **messages**: JSONB array of messages including role, content, and timestamp.
   - **token_count**: Total number of tokens used in the session.
   - **cost_usd**: The cost calculated for the session.
   - **created_at**: The timestamp of when the chat session started.

4. **Leads Table**:
   - **id**: Unique identifier for each lead (UUID).
   - **agent_id**: Foreign key linking to the agent's ID.
   - **name**: The name of the client.
   - **phone**: The client's phone number.
   - **email**: The client's email address.
   - **follow_up**: The date for follow-up.
   - **status**: The status of the lead (New, Contacted, Follow-up).
   - **created_at**: The timestamp of when the lead was captured.

This data storage setup ensures that each agent's interactions and associated files are properly tracked and managed. For further details, you might refer to the specific sections in the Multi-Tenant AI Chat Agent System documentation.
